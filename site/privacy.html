Política de privacidad

Última actualización: 3 de octubre de 2026.

Esta política describe el tratamiento de los datos en Second Brain, una aplicación privada de organización personal mantenida por Antiloope.

Datos a los que accede y para qué los usa

La aplicación guarda la información que introduce su titular: notas, tareas, proyectos, etiquetas, listas e historial de compras y archivos adjuntos. Se utiliza para ofrecer sus funciones de organización personal.

Las conexiones con Google requieren autorización del titular mediante OAuth:

Google Calendar
Accede a eventos del calendario principal, incluidos títulos, descripciones, fechas, horarios y ubicaciones, para consultarlos, crearlos y actualizarlos desde la agenda. El permiso solicitado es de acceso a Calendar; las operaciones implementadas se realizan sobre el calendario principal.
Gmail
Accede a etiquetas y mensajes, incluidos remitentes, destinatarios, asuntos, fechas, fragmentos y cuerpos, para su consulta. El permiso de modificación permite cambiar etiquetas y enviar mensajes a la papelera cuando el titular lo solicita.
Google Drive
Cuando se habilita esta función, crea, consulta y elimina copias de seguridad cifradas para respaldar la aplicación y purgar copias antiguas. Utiliza el permiso drive.file, limitado a los archivos creados por la app o que el titular comparte explícitamente con ella; no solicita acceso general a todo Drive.

Los datos obtenidos de Google se utilizan para estas funciones, sin publicidad, venta de información ni entrenamiento de modelos de inteligencia artificial.

Almacenamiento y protección

La base de datos, los adjuntos y los archivos de autorización se guardan en la infraestructura propia del titular. Los tokens de acceso y renovación permiten mantener la conexión autorizada con Google y deben conservarse con acceso restringido.

Cuando se habilitan las copias de seguridad, se cifran antes de subirlas a Drive. La clave privada necesaria para recuperarlas queda bajo control del titular, fuera del servidor que produce los backups. Las copias pueden contener información personal guardada en la base y los adjuntos.

Las consultas a Calendar y Gmail pasan por el servidor de la aplicación para atender las solicitudes del titular. La conexión con las APIs de Google utiliza HTTPS.

Transferencias y acceso de terceros

La aplicación intercambia con Google los datos necesarios para ejecutar las operaciones autorizadas. Si se habilitan backups remotos, Google Drive recibe los archivos cifrados.

Second Brain no vende datos ni los comparte con anunciantes. El titular administra su infraestructura y decide quién tiene acceso a ella y a las claves de recuperación.

El uso y la transferencia de información recibida de las APIs de Google se ajustan a la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado.

Conservación, eliminación y revocación

La información se conserva mientras el titular la necesita para su uso personal. Algunas operaciones de eliminación de la aplicación marcan registros como eliminados; la eliminación definitiva de registros, adjuntos y archivos de autorización requiere que el titular gestione su almacenamiento.

Las copias de seguridad pueden conservar información eliminada de la aplicación hasta que se purgan o borran. Para una eliminación completa, el titular también debe gestionar las copias locales y las almacenadas en Drive.

Podés revocar el acceso desde las conexiones de tu cuenta de Google. La revocación impide que la app siga accediendo a Google con esa autorización; no elimina por sí sola los datos ya guardados ni las copias existentes.

Privacidad de este sitio informativo

Estas páginas no tienen formularios, cookies propias, analítica ni scripts de seguimiento. No se conectan a la instancia privada de Second Brain ni muestran sus datos.

El sitio se publica mediante GitHub Pages. GitHub puede registrar datos técnicos de las visitas, como la dirección IP, por motivos de seguridad, según su declaración de privacidad.

Responsable, contacto y cambios

El proyecto es mantenido por Antiloope. Para consultas sobre privacidad, consultá las vías de contacto del perfil de Antiloope en GitHub.

Esta política se actualizará cuando cambien las funciones o el tratamiento de datos. Los usos nuevos de datos de Google se comunicarán y se solicitará autorización cuando corresponda.
